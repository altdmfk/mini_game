# 🦖 Dino Jump Mini - Endless Runner Mini Game

웹 브라우저에서 실행 가능한 정통 8비트 아케이드 스타일의 공룡 점프 미니 게임입니다.

---

## 🤖 AI 3줄 요약

* **AI에게 맡긴 일**: HTML5 Canvas 기반의 delta-time 물리 렌더링 엔진 구축, 점프 버퍼링(Jump Buffering) 및 코요테 타임(Coyote Time) 물리학 알고리즘 구현, 픽셀 유령·흑백 평면 종이배 모자 도트 그래픽 및 Web Audio API 효과음 파형 합성.
* **내가 판단한 일**: 연속 장애물(지상 선인장 + 공중 유령) 발생 시 체공 거리 기반 65px 이상의 착지 런웨이 안전 거리 필수 강제 규칙 정의, 15초 생존 시 공중 유령 몬스터 해금 밸런스 및 42개 통과 시 흑백 평면 종이배 모자 이스터에그 규칙 설계.
* **AI 말을 안 들은 일**: 15초 도달 시 기존 타이머와 겹쳐서 불완전하게 스폰되던 공중 장애물 강제 스폰 방식을 거부하고 템포 큐 스폰으로 수정함.

## 📋 검증 안내서 (Verification Guide)

### 📌 어디로 가나요
* 브라우저(Chrome, Edge 등)에서 https://altdmfk.github.io/mini_game/로 접속합니다.

### 🎮 무엇을 하나요 (3단계 이내)
1. **시작**: 화면 클릭 또는 **`Space`** 키를 눌러 공룡 런을 시작합니다.
2. **플레이**: **`Space`** / **`Up Arrow`** / **`화면 터치`**로 장애물(선인장 및 공중 픽셀 유령)을 점프하여 피합니다.
3. **재시작**: 충돌 시 **`FAILED`** 상태 및 하단 기록을 확인한 뒤 **`Space`**를 눌러 새 판을 시작합니다.

### ✅ 무엇이 보이면 통과인가요
* **상태 전환 명확성**: `READY` → `PLAYING` → `FAILED` 상태가 중앙 오버레이와 상단 상태 배지에 명확히 구분됩니다.
* **오류 0건**: 10분 이상 실행 및 플레이 중 F12 개발자 도구 콘솔에 빨간색 레벨 오류가 0건입니다.
* **데이터 보존 및 복구**: 게임 재시작 시 현재 판은 초기화되나 최고 점수(High Score)와 총 플레이 횟수는 보존되며, LocalStorage 데이터가 비거나 손상되어도 기본값으로 안전하게 복구됩니다.
* **반응형 & 접근성**: 다양한 해상도에서 가로 넘침(Horizontal Scrollbar)이나 버튼 잘림이 없으며, 음소거 및 움직임 감소(Reduced Motion) 옵션이 정상 작동합니다.

### ❓ 안 될 때
* 데이터가 비정상일 경우 하단 **`🗑️ Reset Stats`** 버튼을 눌러 초기화합니다.
* 사운드가 안 들릴 경우 브라우저 보안 정책 해제를 위해 화면을 한번 클릭해 주세요.

## 🎮 주요 조작 및 단축키 안내
* **점프 / 게임 시작 / 재시작**: `Space` / `ArrowUp` / `화면 터치(Click)`
* **일시정지 / 재개**: `P` 키 또는 `⏸️ Pause` 버튼
* **이스터에그 (종이배 모자)**: 장애물 42개 통과 시 자동 해금 (해금 후 상단 `⛵ Hat: On/Off` 버튼으로 토글)
